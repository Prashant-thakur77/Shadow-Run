The price is our plan. The costs are measured: inference from the benchmark’s own records, and the VX1 host, control VM and bucket at Vultr’s list prices.

Prod is the customer's own database, so it isn't counted. The VX1 cost is an upper bound: the whole host for the task's whole wall time, although a host runs several rehearsals at once. A second database on the same deployment adds only its variable cost. The README's Unit economics table has the same numbers, from the same function.

The agent never gets the credential

It sends plans to Shadow Run, which holds the only prod login. The model proposes, Postgres measures and frozen checks decide.

1

Freeze. The exact steps and the guardrails, hashed together.

2

Read. A static gate parses it. What it can’t read counts as unsafe.

3

Rehearse. A full clone in a fresh microVM, with no network and no secrets.

4

Measure. Rows per table, each cascade traced to its step. No model involved.

5

Check. Frozen guardrails. A failure goes back to the agent.

6

Approve. A second clone agrees, an undo is proved, a different person signs the hashes.

7

Apply. The same plan runs on prod in one transaction, and rolls back if anything differs from the rehearsal.

The model proposes and explains. Postgres measures. Frozen checks decide. The agent reaches this through MCP, the web app or the CLI, with no database URL or SSH key. Apply compares row counts, row content, schema and guardrails with the rehearsal.

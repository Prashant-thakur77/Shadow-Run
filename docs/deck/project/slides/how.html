The agent never gets the credential

1

Freeze. SHA-256 of the exact steps, with the guardrails hashed alongside.

2

Read. A static gate parses it. What it can’t read counts as unsafe.

3

Rehearse. A full clone in a fresh microVM, with no network device and no secrets.

4

Measure. Postgres reports rows per table, and traces each cascade to its step. No model involved.

5

Check. Frozen guardrails the agent can’t edit. A failure goes back to the agent.

6

Approve. A second clone agrees and an undo is proved. Then a different person approves those exact hashes.

7

Apply. The same plan runs on prod in one transaction. If counts, row content, schema or guardrails differ from the rehearsal, it rolls back.

The model proposes and explains. Postgres measures. Frozen checks decide. The agent reaches this through MCP, the web app or the CLI, with no database URL or SSH key.

Two VMs on one VPC Network, plus Managed Postgres, Object Storage and Serverless Inference. VX1 runs the rehearsal microVMs on KVM; Cloud Compute runs the control plane, web app and MCP server; every LLM call goes to Serverless Inference. The microVM gets a clone and a plan, never a credential. infra/provision.py builds the whole stack and infra/teardown.py removes it, confirming each resource returns 404.
